# Helios gameplay demonstrations — release recording plan

All footage must be real game footage from the approved frontend. Use a dedicated demonstration account. Hide personal email, browser notifications, admin panels and payment information. Do not advance the production clock or fabricate match results. The official release is 1 December 2026 at 07:00 CET.

## Demo 3 — Match day (post-launch only, 30–45 seconds)
Record an actual played match after the official game starts; show preparation, the match timeline/replay, final score and statistics. Do not present the independent scoring proxy as gameplay footage. Show real ranking/finance changes only when available.

## Delivery and verification
- Capture clean 1080p landscape footage, with readable UI and no debug overlays.
- Make a 9:16 crop only if all key UI remains readable.
- Use original or licensed music and verify the footage contains no account information.
- Add subtitles; keep the website call to action visible for the final 3 seconds.
- Before release: record demos 1–2 with existing test career and approved frontend. Demo 3 requires real match evidence after launch or approved isolated test.
- Status: recording scripts complete; actual recordings, edits, exports and publication not yet completed.
