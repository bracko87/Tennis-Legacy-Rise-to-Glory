# Private Tennis Legacy React pilot
This separate entry uses React and the existing Tennis Legacy replay scoreboard CSS without importing the live App, auth provider, analytics or Supabase client. Build only with node scripts/build-ace-pilot.mjs (requires npm ci once). Generated files are ignored. The Node-only tournament launcher serves /react on 127.0.0.1:8766 when built. Normal production routing/build is unchanged. Login remains local and does not authenticate an actual Tennis Legacy account.
Optional ACE_PLAYER_FILE: absolute private JSON outside repository with schema ace-player-v1 and one player/skills pair in the same shape as sample-legacy-snapshot.json players[0]. Only the designated player is replaced; opponents remain synthetic. Use an explicitly exported own-player snapshot; never include email, password, token or owner_user_id. The imported player's state is stored in a separate private-player-draw-v1 directory. An existing draw is retained and not overwritten by a changed input. No database export or live login is performed by this code. No game clock, real tournament, production finance or ranking changes. Build and HTTP tests do not prove browser acceptance.
