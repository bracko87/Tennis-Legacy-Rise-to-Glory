# v0.23C exclusive finalization rehearsal
The v0.23B native engine suite and PostgreSQL settlement staging passed. Chromium installed and reached live matches, but the exact Serve accessibility locator timed out; explicit labels now added to both review interfaces.
This rehearsal uses only ace_review. The new immutable match claims assign one engine (ace or legacy) to each source match and bind participant order and optional feeder match IDs. Finalization serializes by competition, requires verified participant order and a complete claim count, checks winners against already finalized feeder rows in receipt order, copies the staged export and prize proposals into immutable review tables atomically. Identical concurrent requests return already_finalized; a legacy-owned match or wrong feeder rejects the whole transaction. A failed last match leaves zero finalized rows/prizes. The trusted test fixture supplies feeder claims; no authoritative production feeder read or legacy engine modification. No actual finalizer, tax processor, injury roll, career mutation or production migration. Production cutover requires a shared engine claim integrated in both real engine start/finalizer paths and a tested official trigger contract.
