# Unified private world v0.16

Opt-in ACE_WORLD_TEST=1 (with optional ACE_TOURNAMENT_PEER=1) starts the separate browser on port 8767 and an independent world-v1 directory. Use the existing React build command, then start-tournament.cjs. All existing single-draw and multiplayer state is retained. The world worker keeps clock, held fixtures, live simulation, draw advancement, support events, results, private finance and ranking contributions in one persisted state. Only a fresh clock sample can release a held fixture; normal real-time draw progression cannot start it. Browser uses the same authenticated endpoints, with a world calendar, match gate, private balance and result/gear summaries. Own-match commands are isolated by existing ownership rules. The demo uses fixed 60x synthetic game clock, four game days of scheduled slots, synthetic reward amounts and synthetic staff/gear for p0; actual imported skills optional. It is not the current production calendar or reward catalogue. The live standard timing remains unchanged. Phase end or injury can hold a match; no automatic walkover, new injury roll, day-off or tax processing. Support applies supplied gear wear, missing-gear ratings, staff fatigue reduction and computed post-match risk; active injury blocks admission. No real inventory or staff data read. Completion day is conservatively the observation day. No distributed transactions, production scheduler, official React routing or production deployment. Single-writer local file replacement only. Test verifies a complete tournament using controlled clock samples, persistence reopen and private payouts/publication. The opt-in browser is not yet manually accepted.
