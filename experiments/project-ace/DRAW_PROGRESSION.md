# Private draw progression

The isolated draw module accepts explicit bracket slots and qualifying sections, not a production draw publication. Each section contains 2, 4 or 8 players; each winner occupies its designated main-draw slot. Main draws contain 2–32 filled slots (powers of two). No byes, withdrawals, lucky losers, ranking-based seeding, doubles or production bracket changes are implemented. Each phase advances once all currently scheduled matches in that round finish; this deliberate round barrier simplifies scheduling. Multiple courts can operate concurrently. Every match is automatic-coaching on both sides in this module; manual multiplayer remains in the single-match and lifecycle service, not wired to draw selection yet.

Career condition uses the existing SQL calculate_match_fatigue_v2 / apply_match_condition_effects_v1 coefficients from 20260904145237 and simulated_tennis_duration_minutes_v1 from 20261117111500. Temporary in-match fatigue is not added again. The isolated registry carries only career fatigue, sharpness, morale, confidence and focus to the next match, once per match/player. No simulated days or between-round day-off recovery, injury effects, ranking points, prize payments, staff or inventory writes. Court clearance/player rest are the existing compressed test intervals. Production parity is not claimed.

Run node experiments/project-ace/tournament-draw.test.cjs. Tests run qualification, main draw and final, check rest/persistence via lifecycle, and compare an uninterrupted run with a restarted run. This is not yet the website or a live production scheduler.
