# v0.23F-B — field-lock and performance review

Field lock is a pure pre-draw planner following checked-in 20260911112127: late-close gate, start gate, already-locked and existing-draw guards, withdrawal of active medically unavailable entrants, and private human withdrawal notice proposals. Exact competition-return day is eligible. Requires explicit ordered AI reserves and phase eligibility; refuses missing health snapshots and returns replacement_required if no valid reserve. Does not change already-seeded worlds or claim to reproduce official reserve-selection SQL. Official entry and application writes, actual field lock and draw creation remain separate integration work.

Optional autoHealth.performanceEffects:true requires explicit base penalties and skill effect snapshots. Review uses linear remaining-recovery scaling, capped general penalty 35%, per-skill penalty 40%; only applies at admitted match checkpoint, after availability gate, never to permanent roster. Generated records retain supplied catalogue effects. Unsupported skills (smash, slice, volley) are retained but not currently consumed by the Ace point model. This is a proposed mapping, not an exact verified reproduction of the production match engine. Existing worlds unchanged; official health performance equivalence, injury/illness production feeds and settlement still pending. No production access. Automated tests added.
