# World compatibility review v0.11–0.13 (isolated)
No production queries, writes, RPC registration or migrations. world-clock.cjs consumes the existing get_game_clock_v1 response and uses the 366-day calendar and Monday week offset from 20260828181500, 20261111153206 and 20261117112500. Fresh clock samples are required for admission; paused clocks prevent new starts but already-live matches run on real time. Clock rollback fails closed. clock-runtime.cjs is a fixed-fixture admission harness, not the existing React draw or official worker. It does not fetch the live clock or allocate future matches from real draws. The gate is a conservative adaptation of ensure_safe_singles_start_v1: phase bounds, 10:00–21:30 candidate slots, 30-minute grid, 15 game-minute court clearance, 60 game-minute player recovery, cross-competition same-day block, active resource hold until actual completion. Completion time uses the observed game minute when between samples; exact game-time reconstruction and complete deployed rule parity remain unverified.

isolated-settlement.cjs projects terminal draw results, qualifier bonus, gross taxable human prize credit, pending weekly ranking results and contribution replacement/expiration. Rules are inspired by 20260904115546 and 20260918102000; reward values must be explicitly provided as a snapshot (test amounts synthetic). No actual payout catalogue, tax calculation, official rank order, finance account, prior career history, withdrawal handling, database transaction or production result finalizer. Publication uses season-relative Monday and 366-day expiration checked at publication. No official game records changed. The two harnesses share the existing isolated engine but are not wired into the browser or combined into a deployed world worker; the test separately runs the clock-admission harness and the full draw/settlement harness.

A due fixture held by a live resource does not reserve a separate free court against an independent match in the same tick. Admission stays within the local 10:00–21:30 start window.
