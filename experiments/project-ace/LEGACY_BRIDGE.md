# Isolated Tennis Legacy bridge

This is a local data adapter and replay projection, not production integration. The example JSON contains synthetic data only. A local admin can set ACE_SNAPSHOT_FILE to a private JSON file outside the repository, then restart the Node-only launcher. The imported fixture option appears at login. The local delay controls test start; official schedule fields are descriptive only. The snapshot requires player and skill rows (matching player_id), scheduled match metadata, and optional weather/equipment preset. Do not commit real player rows, credentials or owner IDs. Source player IDs are used only to validate the snapshot, not published as replay IDs. Imported profiles use V1 weighted ratings and the context v0.5 model. ATP Grand Slam main draw uses best of five; other supported singles formats use best of three. This rule follows the documented main-draw policy; the old SQL code checks category without distinguishing qualifying.

GET /api/replay returns a local ReplayResponse-compatible projection with elapsed events and no winner or final score before completion. Duration is intentionally unknown until completion; the production sealed simulation system cannot be reused unchanged. No database RPC calls, official result registration, real scheduler or live website route changes. Production compatibility still requires an authoritative incremental worker, isolated persistence and a new safe scheduling/finalization path. No official career, ranking, inventory or financial effects.
