# Context v0.5 isolated pilot

New fixtures use context v0.5. Legacy checkpoints retain their engine and advice. Weather and equipment presets are synthetic; style modifiers are partial adaptations of the existing SQL, not production parity. Playing hand has no baseline bonus; opposite hands add a small conditional backhand-target adjustment, inspired by the existing geometry rule. Equipment missing penalties use the SQL rating multipliers; performance equipment is a fixed synthetic +2% rating preset. Actual inventory, staff, injuries, weather delays, production player import, and full shot-level style parity remain unimplemented. Advice uses only public styles, observed conditions and recent results (last 48 points once at least 24 are available). No opponent tactics or future points are provided to the advice function. Calibration JSON is an exploratory 540-match skill-gap sweep plus 120 matches for one auto-coaching comparison; no production match distributions used. All random seeds paired where relevant; sample size 60 per cell.
