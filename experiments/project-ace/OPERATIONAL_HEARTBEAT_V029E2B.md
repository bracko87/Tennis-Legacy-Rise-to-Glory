# E2-B — worker heartbeat review
Extend the disposable pilot control with controller-registered generation and monotonic sequence. Only the isolated Ace engine role can publish a pulse; database observation time cannot be supplied by the caller. Replays do not refresh liveness. Restart registration fences old generations. Missing or stale heartbeat warns while pilot is active; with unfinished owned matches it recommends operator stop review, not automatic mutation. Stopped pilots can still pulse while draining. 60 real seconds is a provisional review threshold. Test includes role separation, sequence replay, restart fencing, missing heartbeat with an owned match, recovery and guarded stop. This is an observation contract, not verified process identity or an integrated production worker loop; the role credential and reported generation do not prove a unique physical process. Stale classification is implemented but no timed expiry test yet. No production deployment or changes.
