# Private tournament browser pilot

Run node experiments/project-ace/start-tournament.cjs with ACE_ADMIN_EMAIL already set. Open http://127.0.0.1:8766 and use the new temporary local password. Separate state directory ~/.tennis-ace-offline-v1/draw-v1; existing single-match state is untouched. One persistent seven-player demo (four qualifiers, three direct entrants, two courts); the designated player enters the main draw. Select any match to watch; only the designated player's matches allow coaching. Hybrid mode falls back to automatic when not watching the managed match. The scheduler keeps running independently of browser sessions; restart catches up elapsed time. No reset button: completed draw remains available. Synthetic local identity only; no production access, real player import, multiplayer tournament accounts or official career effects. Round scheduling remains compressed; no production clock bridge. Browser UI reuses local match center, not the production React site.
