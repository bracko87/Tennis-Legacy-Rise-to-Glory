# v0.23F-A — isolated automatic health lifecycle

Explicit opt-in config autoHealth: {catalog:[...]} requires medicalWalkovers:true, complete supplied support for all entrants and unique health record keys. Imported illness and injury records share availability/recovery logic; no automatic illness generation. Uses deterministic existing injury review selection with competition-scoped synthetic match identifiers, and current isolated match risk formula, not authoritative live risk. Both played participants receive one recorded roll including clear outcomes; W/O does not create match workload or injury rolls. Existing synthetic worlds unchanged. Recovery advances on absolute game days, emits private training/competition/full-recovery notices for crossed dates, and never replays already-emitted events. Older imported records are normalized without historical notifications. Exact competition-return day allows match play. React review UI displays private records and notices.

Test uses an explicitly artificial one-row catalogue and deterministic seed search, not live medical data. Date attribution uses existing worker observation day, not interpolated completion time.
