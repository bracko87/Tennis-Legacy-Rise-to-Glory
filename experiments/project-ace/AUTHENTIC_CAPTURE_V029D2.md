# D2 authentic catalog capture
Run only after explicit approval of the two database endpoints. Use private PostgreSQL service profiles with sslmode=verify-full, trusted root certificate, and a private password file; no passwords in commands or chat. Verify service profile has no options overriding read-only or TLS settings. Restore must be isolated and cron disabled before capture. The wrapper provides read-only defaults, and the SQL itself begins a read-only transaction. A local receipt is an integrity hash, not proof of source identity. Keep outputs outside Git, e.g. a private directory. Use separate reference and restore profiles and source labels. Compare with restored-schema-gate.cjs restored.json reference.json. No automated production authorization.
